# 실측 — 표 · 측정 조건 · 주의

이 저장소의 모든 숫자를 한곳에 모았다. 다른 문서의 숫자는 전부 이 문서와 같아야 한다.

## 측정 조건

| 항목 | 값 |
|---|---|
| 기간 | 2026-10-08 ~ 2026-10-09 |
| 지휘 | `laptop` — M5 Max 128GB |
| 상시 도구 | `homemac` — M3 Max 64GB |
| 가벼운 도구 | `air` — M2 8GB |
| 연결 | Tailscale + ssh 키 인증(ssh 별칭), ssh ControlMaster 연결 재사용 |
| 원격 브라우저 | 각 맥의 GUI cmux 를 소켓 비밀번호로 원격 조종 |
| 세션 기록 | `~/.claude` 를 Syncthing 으로 동기화 → 노트북 세션 기록(.jsonl)이 홈맥에도 있다 |
| 비용 | 구독 로그인으로 실행했고, 표의 달러는 **API 단가로 환산**한 값이다 |

측정은 내 맥 세 대와 내 네트워크에서 한 번 또는 몇 번 잰 값이다. 다른 환경에서 같은 숫자가 나온다는 보장은 없다.

| 방식 | 시간 | 대리인 토큰 |
|---|---|---|

| 방식 | 비용 | 시간 |

## 비용 환산 주의

- **API 단가 환산이다.** 나는 구독으로 실행했다. 표의 달러는 같은 토큰을 API 로 썼다면 얼마였을지를 계산한 값이고, 실제 청구액이 아니다.
- **Haiku 비용은 실제보다 높게 찍혔을 수 있다.** 홈맥의 claude 가 구버전이라 Haiku 모델을 인식하지 못했고, 그래서 Sonnet 단가로 계산됐을 가능성이 있다. Haiku 가 들어간 행(브리프+Haiku, 실전 재현 카드, verify·mine·research)이 여기에 해당한다.
- **LLM 단계가 들어간 값은 범위로 읽는다.** 같은 입력에도 결과 길이와 비용이 달라졌다.
- **지휘 세션의 토큰은 대부분 표에 없다.** 표는 원격 도구와 작업자 쪽 비용이다.
