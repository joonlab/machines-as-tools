# 도구 카탈로그 — multimac MCP 도구 19개

MCP 서버 `multimac` 의 도구 19개다. 도구 설명(docstring)이 곧 라우팅 규칙이라, 아래 "쓸 때 / 쓰지 말 때"는 Claude 가 실제로 읽고 고르는 문장을 요약한 것이다. 실측은 2026-10-08~09, 비용은 API 단가 환산이다. 조건과 주의점은 [benchmarks.md](benchmarks.md)에 있다.

## 세 층

| 층 | 수 | 무엇 | 도구 |
|---|---|---|---|
| 기본 도구 (primitives) | 8 | 명령줄 정본 `mm` 을 그대로 노출 | `status` `run` `read_url` `browser` `close_tab` `ask` `fork` `batch` |
| 조합 도구 (composed tools) | 9 | 기본 도구를 조합한 일 단위 도구. `mm` 을 고치지 않는다 | `render_remote` `render_check` `verify_judge` `verify_check` `verify_status` `mine_scan` `mine_sessions` `research_repo` `research_reports` |
| 라우터 (router) | 2 | 기기 대신 능력 이름으로. 상태를 재고 첫 통과 기기에 보낸다 | `auto_dispatch` `auto_capabilities` |

## 기본 도구 — primitives

### `status()`
- **단계·실측**: T0 · 0.5초 · LLM 0
- **무엇**: 세 기기의 메모리 여유·claude 프로세스 수·부하를 한 화면에.
- **쓸 때**: 무거운 일을 보내기 전 판정. 진행 중 확인.
- **쓰지 말 때**: —

### `run(host, command)`
- **단계·실측**: T0 · 원격 셸 실행 0.2초(연결 재사용 시 ssh 왕복 0.04초) · LLM 0
- **무엇**: 그 기기의 셸에서 명령을 실행한다. 출력은 `max_chars` 로 자른다.
- **쓸 때**: 빌드·집계·파일 처리처럼 할 일이 정해진 일.
- **쓰지 말 때**: 에어에 무거운 명령. 판단이 필요한 일(→ `ask`). 삭제처럼 되돌릴 수 없는 일.

### `read_url(url, host="air")`
- **단계·실측**: T0 · 2~7초 · LLM 0
- **무엇**: 원격 cmux 브라우저로 열고 → 본문을 읽고 → 탭을 닫는다.
- **쓸 때**: 페이지 읽기. 로그인 세션이 필요한 사이트 읽기.
- **쓰지 말 때**: 클릭·입력이 필요한 흐름(→ `browser`).

### `browser(host, args)`
- **단계·실측**: T0 · LLM 0
- **무엇**: 클릭·입력·스크린샷 등 cmux browser 세부 조작.
- **쓸 때**: 여러 단계 웹 조작.
- **쓰지 말 때**: 읽기만 할 때(→ `read_url`). 연 탭은 반드시 `close_tab` 으로 닫는다.

### `close_tab(host, surface)`
- **단계·실측**: T0 · LLM 0
- **무엇**: `browser` 로 연 탭을 닫는다. `surface:N` 형식만 받는다. 인자가 비면 엉뚱한 탭(호출자 탭)이 닫히는 사고를 형식 검사로 막는다.
- **쓸 때**: `browser` 로 연 탭을 다 쓴 직후.
- **쓰지 말 때**: `read_url` 을 쓴 경우(이미 닫는다).

### `ask(prompt, model, brief, resume_worker)`
- **단계·실측**: T1·T2 · Haiku 0.6~9센트 · Sonnet 3~6센트 · 2~40초. 가벼운 구성 맥락 26,934 토큰(기본 구성 95,209). 같은 작업자 이어 쓰기 시 새 캐시 225 토큰.
- **무엇**: 홈맥의 가벼운 claude 작업자. 빈 설정 디렉터리에 도구를 줄여서 띄운다.
- **쓸 때**: 요약·분류·카드·판정. 같은 브리프를 여러 작업자가 공유할 때. 이어서 시킬 땐 `resume_worker`.
- **쓰지 말 때**: 삭제·발송 같은 되돌릴 수 없는 일(안전 훅이 없다). 대화 맥락이 꼭 필요한 일(→ 드물게 `fork`).

### `fork(session_id, prompt)`
- **단계·실측**: T3 · 26만 토큰 세션 1회 $2.14 · 약 10초. 비용은 맥락 크기에 비례한다.
- **무엇**: 지휘 세션 대화 전체를 다른 기기에서 복제한 분신.
- **쓸 때**: 브리프로 옮길 수 없는 미묘한 대화 맥락이 꼭 필요할 때만.
- **쓰지 말 때**: 대부분의 경우. 같은 요약 작업이 `ask` + 브리프로 $0.0146, 약 147배 쌌다.

### `batch(jobs)`
- **단계·실측**: 단계는 작업마다 다름 · 단순 3기기 0.9초 · 대리인 토큰 0. Workflow 대리인 3개(36초·토큰 약 22만)를 대신해 6.2초.
- **무엇**: 여러 기기·여러 작업을 동시에 실행하고 요약표만 돌려준다. 시작·끝 시각을 기록한다.
- **쓸 때**: 동시 분배의 기본값.
- **쓰지 말 때**: 항목마다 LLM 판단이 필요한 긴 오케스트레이션(→ Workflow).

## 조합 도구 — composed tools

### `render_remote(project, mode)`
- **단계·실측**: T0 · 스틸 3장 원격 렌더 왕복 2.3초 · 2초 구간 영상 18.6초 · LLM 0. 71초 컨셉 영상도 이 도구로 홈맥에서 렌더했다(도중 홈맥 부하가 급등하자 렌더러가 115초 동안 스스로 일시정지했다가 재개).
- **무엇**: 영상 프로젝트를 홈맥으로 보내 렌더하고 산출물만 회수한다. 노트북 메모리를 쓰지 않는다.
- **쓸 때**: 노트북에 무거운 작업·세션이 많을 때. 메모리 부족으로 기기가 멈추는 것을 막고 싶을 때.
- **쓰지 말 때**: 노트북이 한가하고 스틸 1~2장만 볼 때.

### `render_check(project)`
- **단계·실측**: T0 · LLM 0
- **무엇**: 홈맥 쪽 렌더 전제와 부하 게이트를 확인하고, 실제로 보낼 내용을 미리 보여 준다.
- **쓸 때**: `render_remote` 직전.
- **쓰지 말 때**: —

### `verify_judge(files, criteria, model)`
- **단계·실측**: T1·T2 · 20~33초 · $0.05~0.12
- **무엇**: 그 산출물을 만들지 않은 다른 작업자가 판정하고, 파일과 기준의 해시를 장부에 동결한다. OpenRig 의 증거 동결 패턴을 빌렸다.
- **쓸 때**: 납품·공개 전 게이트. 생성자와 다른 눈이 필요할 때.
- **쓰지 말 때**: 결정론으로 확인 가능한 것(grep·테스트·건수 대조 → `run`). 중요한 판정을 Haiku 한 번으로 끝내는 것 — 같은 입력에 fail/pass 가 갈렸다.

### `verify_check()`
- **단계·실측**: T0 · 0.03초 · LLM 0
- **무엇**: 장부를 재검사한다. 판정 뒤 파일이 바뀌었으면 unknown, 장부가 변조됐으면 broken.
- **쓸 때**: 판정을 근거로 무언가 내보내기 직전.
- **쓰지 말 때**: —

### `verify_status(files, criteria)`
- **단계·실측**: T0 · LLM 0
- **무엇**: 지금 파일·기준에 맞는 유효한 판정을 조회한다.
- **쓸 때**: "이 pass 가 아직 유효한가"를 LLM 없이 확인할 때.
- **쓰지 말 때**: —

### `mine_scan(pattern, since)`
- **단계·실측**: T0 · 세션 248개(1.2GB) 2.2초 · 535개(2GB) 3.3초 · LLM 0
- **무엇**: 홈맥에 동기화된 세션 기록에서 키워드 적중 세션 순위를 매긴다.
- **쓸 때**: "그 작업 어느 세션이었지".
- **쓰지 말 때**: 내용 요약이 필요할 때(→ `mine_sessions`).

### `mine_sessions(pattern, since, question)`
- **단계·실측**: T0+T1 · 스캔 2.2초 + Haiku 3묶음 동시 → 약 40초 · $0.30~0.35. 다시 돌리면 카드 수가 달라진다.
- **무엇**: 스캔 → 묶음 → Haiku 작업자 동시 카드 작성. 지휘 세션에는 짧은 요약과 경로만 돌아간다.
- **쓸 때**: 회고·주간 정리·작업 목록 뽑기.
- **쓰지 말 때**: 세션 하나의 상세 경위. 정확도가 곧 품질인 납품물(카드는 초안이다).

### `research_repo(url, focus)`
- **단계·실측**: T0+T1 · 공개 레포(modelcontextprotocol/python-sdk) 1차 개요 약 40초 · $0.23~0.27
- **무엇**: 홈맥이 클론·집계, 에어가 레포 페이지 읽기를 동시에 하고, Haiku 작업자가 근거 경로를 붙인 요약 보고서를 쓴다.
- **쓸 때**: 처음 보는 오픈소스를 도입할지 판단하는 1차 개요.
- **쓰지 말 때**: 이미 아는 레포의 질문 하나. 거대 모노레포. 깊은 품질·보안 감사.

### `research_reports(repo)`
- **단계·실측**: T0 · LLM 0
- **무엇**: 최근 조사 보고서 목록.
- **쓸 때**: 같은 레포를 다시 조사하기 전에 이미 있는 보고서를 확인할 때.
- **쓰지 말 때**: —

## 라우터 — router

### `auto_dispatch(capability, args)`
- **단계·실측**: 배정 판정 LLM 0 · heavy → homemac 0.44초
- **무엇**: heavy·judge·browser·light 중 하나를 부르면 후보 기기 상태를 재고 첫 통과 기기에서 실행한다. heavy 는 homemac, browser 는 air 가 우선이다. homemac 이 STOP 이면 laptop 으로 떨어지고, 후보가 전부 STOP 이면 실행을 거부한다.
- **쓸 때**: 기기를 의식하지 않고 일을 보낼 때.
- **쓰지 말 때**: 특정 기기에만 있는 파일·로그인 세션이 필요할 때(→ `run`/`read_url` 에 host 명시). 여러 작업 동시 실행(→ `batch`).

### `auto_capabilities()`
- **단계·실측**: LLM 0
- **무엇**: 능력 → 기기 우선순위와 지금의 배정 결과 미리보기.
- **쓸 때**: 배정이 어디로 갈지 먼저 볼 때.
- **쓰지 말 때**: —
